about=
    This plugin is part of the xDEM Python package, a collaboration between CNES (the French space agency) and GlacioHack (a group of glaciology researchers).

    Python dependencies are installed automatically the first time the plugin runs. The installation may take a few minutes, please do not close QGIS during this process.

changelog=This new version runs the installation process in the background and notifies users of its status, it also adds MacOS compatibility.
